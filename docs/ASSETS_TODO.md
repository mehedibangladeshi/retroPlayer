# Assets TODO

Missing or broken assets. Each item: what is missing, current workaround, what the artist should provide.

1. **SVG layers are unusable duplicates.** `source/cassette/audio-red-{base,mid,reel}.svg` are byte-identical (36,383 B each), `source/player-body-base.svg` equals `source/player-body-top-cover-and-utility.svg` (136,900 B), and `source/cassette-player.svg` and `source/player-body-bottom-part-with-boltu.svg` are whole-composition exports. Workaround: the PNG layers are used. Provide: one SVG per layer containing only that layer (rules in AGENTS.md prefer SVG).
2. **Both reels share one layer** (`cassette/audio-red-reel.png`). Workaround: the layer is separable: the renderer draws it twice, each copy clipped to a circle around one hub (`REELS`), and rotates each copy independently; reel centres and radii are measured in `layout.ts` (`REELS`). Provide: a separate graphic per reel (or one reel graphic, drawn twice), centred on its hub, plus the cassette without reels behind them.
3. **No pressed or disabled button states.** One buttons sheet (`body-buttons.png`) holds the five keys. Workaround: CSS effects (translate, brightness, opacity) on slices at `BUTTONS` rects. Provide: each button in normal, pressed and disabled states, with icon.
4. **Button text labels (PAUSE, REWIND, ...) are baked into `body-bottom.png`**, not the buttons layer, so they cannot be restyled or localised. Workaround: none needed for now. Provide: labels as a separate layer if they should change state.
5. **No tape layer.** There is no wound-tape graphic on the reels, so the tape-amount animation (tape moving from left to right reel) is not possible. Workaround: skip it, or a CSS-drawn placeholder disc behind the reels if later required. Provide: tape discs (left and right) as separate layers, with a transparent hub.
6. **Text slots are baked in.** The cassette label has no empty title area (the grey strip is part of `cassette-mid.png`), and there is no time display, so the track title and time are drawn by code over `LABEL.title` and `LABEL.time` (the time slot is a guess left of "HIGH QUALITY AUDIO"). Provide: confirmation of where the artist wants title and time, and the fonts used for the brand and label text.
7. **Chrome (minimize/close) has no hover or pressed states** and is baked into `body-top-cover.png`. Workaround: transparent hit areas at `CHROME` rects with a CSS highlight. Provide: states for both buttons.
8. **No glass reflection or shadow layer** separate from the top cover; the glare in the window corner is part of `body-top-cover.png`.
9. **Cassette is red only** (`audio-red-*`); no other cassette colours or labels, and the cassette PNG scale was fitted to the reference by measurement, not given by the artist.
10. **Source canvases have no registration data.** The cassette canvas offset relative to the body was found by fitting against the reference JPEG (error about 2/255 mean). Provide: layers exported on one shared canvas, or the cassette position.
11. **No bundled label font.** The title and time on the label use a system font stack, so text rendering differs per OS. This breaks the rule that the UI looks identical on Windows, macOS and Linux. Workaround: the system font stack. Provide: a font file for the label text, for example a condensed typeface that matches "AUDIO RED", licensed for bundling in the app.
12. **Full-screen chrome box was drawn by us.** `png/chrome-fullscreen.png` was drawn for this project from the minimize box, with four corner brackets as the glyph. It is 38x38 at 2x and sits at anchor 697,7 CSS. Workaround: the drawn box. Provide: a full-screen box in the same style as minimize and close, with the same size and anchor, and its states (see item 7).
13. **Pills moved in the artist's source.** The right pill in `body-bottom` was moved 15.5 CSS px outward, so both pills sit 24 px from their side edge, and both pills were moved about 20 CSS px down so they sit centred on the seam between the upper body and the lower panel, like clips holding the two parts together. The seam itself was redrawn as a thinner shaded groove. This was a pixel edit of `source/player-body-bottom-part-with-boltu.png`, and the PNG was regenerated from it. Workaround: the edited PNG. Provide: the artist may want to update their master file to match, or confirm the new pill position.
