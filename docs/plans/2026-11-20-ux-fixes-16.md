## Open questions
Scout facts (2026-11-20):
- Sounds are played by the engine (`playSound` cmd). play/pause/stop send sound+action on `onClick` (mouseup), CassettePlayer.tsx:105-111. Clips resample lazily on first use (sound.rs), so the rarely used `stop` clip pays that cost on its first play.
- Keys: Space → togglePlayPause (click sound). N/P → next/previous, NO sound. Arrows → hold motor (seek sound). No stop key.
- Last track ends: sidecar stays Stopped (main.rs:206-237), no sound. Loop Song = engine `looped`.
- Player-side Open Album / folder drop → `loadAlbum` (engine auto-plays). Rack "+" / rack drop → `rackAdd` → scan only.
- Timer `.cp-time` 11px #6b6c72 (CassettePlayer.css:22). Player title `.cp-title` has NO marquee; marquee is only on the selected playlist row (marquee.ts SPEED=60, infinite alternate).
- Seekbar: useDisplayPosition floors to whole seconds and falls back to raw positionMs between event and next rAF → jitter. Drag release clears dragMs before engine confirms → snap-back.
- Knob: store default volume 1 before first `options`; renderer applies every `options` echo incl. engine defaults after a restart; 500 ms pending timeout can revert.
- All windows scale by transform; player has aspect lock + min height min(308, max(200, 0.3·workAreaH)).
- Rack: no current-album info in RackState; native horizontal scrollbar with no CSS; title bar only header. Per-album position not stored; global Session {path, album, index, positionMs}. rack:play sends loadAlbum without index/play.
- Track rows: `NN. artist – title` when mixedArtists.

- C4 rack:play with a plan → scan tracks via existing previewScans, then `loadAlbum {path: dir, index, play: false}`, `seek {positionMs}` if > 0, `play`. Without a plan → current behaviour (loadAlbum, auto-plays from track 1 0:00). Owner: T10.
- C5 Resume saving: fold the album's resume point from `state`/`position` events like Session; skip while a restore (session or resume) is in flight; persist rack.json on `state`, every 5 s while playing, and before-quit. Owner: T10.
- C6 `trackRowName(track, i)`: "NN. Title" only; mixedArtists no longer used for rows. Owner: T8.
